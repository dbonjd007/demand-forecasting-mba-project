# 📈 Automated Demand Forecasting in E-Commerce

### *Master's Thesis Capstone Project*

> **Title:** *Automated Demand Forecasting in E-Commerce: A Comparative Evaluation of ARIMA, Prophet, and XGBoost on Real Multi-Country Sales Data.*

---

## 📌 Executive Summary

This capstone project evaluates classical time-series statistical models against machine learning algorithms to optimize inventory demand forecasting across multi-region e-commerce datasets. The primary objective is to enhance revenue visibility, reduce stockout risks, and optimize supply chain operations.

---

## 🔬 Comparative Methodology & Framework

1. **Statistical Econometric Models:** ARIMA, Prophet, and XGBoost for baseline seasonal decomposition.
2. **Additive Time-Series Models:** Meta Prophet for handling complex seasonality and holiday trends.
3. **Machine Learning Ensembles:** XGBoost with feature-engineered lag variables, rolling means, and exogenous indicators.

---

## 🛠️ Tech Stack & Dependencies

* **Language:** Python
* **Data Processing & Pipelines:** Pandas, NumPy, SQL Data Pipelines
* **Modeling & Evaluation:** Scikit-Learn, Statsmodels, Prophet, XGBoost
* **Visualization:** Matplotlib, Seaborn, Looker Studio / Power BI integration
